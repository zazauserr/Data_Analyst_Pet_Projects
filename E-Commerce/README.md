# E-Commerce Sales Analysis Project

## Project Goals: 
- Analyze sales data from an e-commerce store.
- Identify the most popular products and top purchasing countries.
- Examine customer behavior and detect loyal buyers.
- Evaluate sales trends, seasonality, and product returns.

## Project Description:
- This project focuses on analyzing e-commerce sales data using the E-Commerce Dataset. The workflow includes data exploration, cleaning, and key metric analysis: top-selling products, geographic distribution of sales, returns analysis, customer purchasing behavior, and time-based trends.

## Tools Used:
- Python 
- Pandas
- NumPy
- Re 
- Matplotlib
- Tableau
