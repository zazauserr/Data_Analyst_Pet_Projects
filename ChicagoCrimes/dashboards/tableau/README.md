# Tableau Visualizations

## Files
Static visualization exports from Tableau analysis:

- `Arrest.png` - Arrest rate analysis by crime type
- `Community_Area.jpg` - Crime distribution by community areas  
- `Crime_Map.png` - Geographic crime distribution map
- `Primary_Type.png` - Crime type frequency breakdown

## Purpose
Supplementary visualizations providing different analytical perspectives on the Chicago crime data. Used for comparison with Power BI dashboard and portfolio demonstration.

## Format
Static image exports (PNG/JPG) suitable for presentations and documentation.

## Note
These are visualization outputs only. Interactive Tableau workbook not included in this repository.
